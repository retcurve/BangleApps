# ![Image](app.png "icon") Message Scroll

Scrolls new messages across the whole screen in a large font, so they can be read
at arm's length.

![Image](screenshot.gif "screenshot")

## Usage

There is nothing to launch. Install it and it takes over when a message arrives.

* **Press the button** (or unlock the watch, if it was locked) while a message
  is scrolling to open it in the normal Messages app.
* Otherwise just wait - it will return to the clock on its own after the set number of repeats.

## Settings

`Settings` -> `Apps` -> `Msg Scroll`:

| Setting | Default | Meaning |
| --- | --- | --- |
| Speed | `Medium` | Scrolling speed. Slow, Medium, or Fast |
| Repeats | `3` | Number of times to scroll the message |
| Font size | `Medium` | Small, Medium, or Large |
| Rotate | `0°` | Screen rotation, in 90 degree steps |
| Colour | `Theme` | Text colour. `Theme` follows the system theme foreground |
| Max bright | `on` | Force maximum LCD brightness while scrolling |
| Don't dim | `on` | Keep the backlight on while scrolling |
