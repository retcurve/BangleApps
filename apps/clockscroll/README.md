# ![Image](app.png "icon") Clock Scroll

Scroll the time and/or date on button press. Note, this runs in addition to the currently selected clock rather than replacing it. 

## Usage

After installation, Clock Scroll will run on unlocking the device. The current time will be scrolled across the screen a number of times before returning to the clock. Tap the screen return to the clock without having to wait. Pressing the button will open the launcher. 

If using `On button` as the run method the time will scroll whenever the device is on the clock screen. 

Launching `Clock Scroll` from the launcher scrolls the time as well, which is
  handy for trying out settings.

## Settings

`Settings` -> `Apps` -> `Clock Scroll`:

| Setting | Default | Meaning |
| --- | --- | --- |
| Run | `On unlock` | What starts the scroll: `On unlock`, `On button`, or `Off` to keep the app installed but stop it taking over |
| Speed | `Medium` | Scrolling speed. Slow, Medium, or Fast |
| Repeats | `3` | Number of times to scroll |
| Font size | `Medium` | Small, Medium, or Large |
| Rotate | `0°` | Screen rotation, in 90 degree steps |
| Colour | `Theme` | Text colour. `Theme` follows the system theme foreground |
| Show time | `on` | Scroll the time |
| Show date | `off` | Scroll the date |
| Max bright | `on` | Force maximum LCD brightness while scrolling |
| Don't dim | `on` | Keep the backlight on while scrolling |

At least one of `Show time` or `Show date` must be enabled.
